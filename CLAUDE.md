# CLAUDE.md

This is a personal dotfiles repository managing shell configs, git settings, and macOS preferences. It uses a **role-based configuration system** keyed on `DOTPICKLES_ROLE`: `home` or `work` from the hostname, `work-coder`, `container` and `claude-code-remote` detected from the environment (detection order in `config/fish/conf.d/dotpickles-role.fish`), or `coi-host` set explicitly.

See [doc/architecture.md](doc/architecture.md) for how the systems fit together.

## Development Commands

```bash
npm run lint      # typecheck + format check (the test suite)
npm run format    # format all files with Prettier
npm run typecheck # TypeScript type check only
```

Pre-commit hooks via `lefthook`: Prettier formats staged files, TypeScript checks `.ts` files.

There are no traditional unit tests. "Testing" means `npm run lint` + manual install verification.

**Sandbox and SSH.** `home`, `work-coder` and `claude-code-remote` run with the command sandbox off ([ADR 0066](doc/adr/0066-turn-off-the-command-sandbox-for-the-home-role.md)); `work`, `container` and `coi-host` inherit it on from `claude/roles/base.jsonc`. The sandbox denies outbound port 22, so agent sessions on `home` and `work` send SSH through the `com.technicalpickles.agent-ssh-relay` SOCKS5 relay, which only reaches hosts listed in `config/gost/agent-ssh-relay.yml` (see [ssh/CLAUDE.md](ssh/CLAUDE.md), [ADR 0055](doc/adr/0055-agent-git-over-ssh-through-the-relay.md)). `home/.gitconfig.d/claude-agent-work` rewrites `https://github.com/` to SSH so https remotes don't fall through to a keychain prompt; only `gist.github.com` stays on HTTPS via `gh`.

## Architecture Decision Records

This repo uses ADRs to document why architectural choices were made. Before making significant changes, check [doc/adr/](doc/adr/) for existing decisions.

```bash
bin/adr new "title" # create new ADR
bin/adr list        # list all ADRs
```

## Important Files Not to Modify Manually

- `~/.gitconfig.local`: Generated by [gitconfig.sh](gitconfig.sh)
- `~/.gitconfig.d/1password`: Generated during git config setup
- `~/.ssh/config`: Managed by [sshconfig.sh](sshconfig.sh) -- edit `ssh/config.d/` instead
- `~/.ssh/config.d/colima`: Generated by [sshconfig.sh](sshconfig.sh)
- `~/.config/1Password/ssh/agent.toml`: Managed by [sshconfig.sh](sshconfig.sh) -- edit `config/1password/agent.toml.<role>` instead (see [ADR 0033](doc/adr/0033-1password-ssh-agent-allowlist.md))
- Any symlinked files -- edit the source in `home/` or `config/` instead

## Herdr Plugins

`config/herdr/plugins.toml` is the source of truth for which herdr plugins get installed (`./herdr.sh`, run standalone or via `./install.sh`). Whenever you `herdr plugin install`/`herdr plugin link` something new, add an entry to `plugins.toml` too -- nothing else keeps it in sync. See [ADR 0046](doc/adr/0046-declarative-herdr-plugin-manifest.md).

## Working with Nerd Fonts / Special Unicode Characters

When editing files with Nerd Font glyphs (tmux config, starship prompt), do not insert glyphs directly -- they get corrupted. Use placeholder text and let the user paste the actual glyph, or define tmux user options:

```bash
set -g @_pill_left "" # user pastes actual glyph
set -g @_pill_right ""
```

Common glyphs in this repo: (U+E0B6), (U+E0B4), (U+E0B0), (U+E0B2)
